## 从观点到 Skill 的处理

| 观点性质 | 如何使用 |
| --- | --- |
| 作者的训练偏好、个人故事与人生观点 | 标为作者观点；其真实性和适用性分开评估 |
| 经第三方接口取得的 X 作者内容 | 保留原帖和读取路径，披露未直接登录核验 |
| 访谈中的生活方法 | 提炼可操作部分，不复述夸张承诺为事实 |
| 跨领域映射、回答流程和情境示例 | 明确属于本项目推演与原创，不假称作者原话 |
| 医学、营养、收益率和趋势判断 | 需要独立证据与个体背景；作者名气不能替代 |

不纳入可执行规则的说法包括：寿命按肌肉与心肺各占 25 分，练薄肌即可保证老年不坐轮椅，有氧总会掉肌肉、可以完全不用做，有薄肌能解决绝大多数疾病，以及无条件相信 AI。它们在材料中出现，不代表已被科学验证。

不因为不采纳这些说法就抹去原作者的表达。用户要研究原观点时，如实说明他讲过什么、材料如何取得、哪里缺少证据。
