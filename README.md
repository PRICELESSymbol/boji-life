# 薄肌生活思维 · boji-life

一个把薄肌思维用于生活选择的中文 AI Skill。

它结合邵艾伦的薄肌内容、《薄肌指南》、邵艾伦与孙宇晨的长访谈，以及 15 条相关 X 帖文。既支持规律力量训练，也把身体、真实能力、反馈和选择权带进学习、工作、消费、关系与人生方向的讨论。

核心主张：**练出身体与真实能力，拿回选择权，用实际反馈调整。**

## 它会怎样帮助你

- 找清楚你真正想改善的事，以及时间、预算和身体等现实限制。
- 比较收益、持续成本、风险和退出难度，给出有条件的建议。
- 提供一个能开始的动作，以及继续、调整或停止的依据。
- 支持训练，也支持恢复、维持、娱乐和主动选择稳定生活。

例如，学习问题会关注能否独立完成任务；消费问题会检查物品是否解决实际瓶颈；职业问题会兼顾技能、机会和退路。不会在每个问题后机械附上健身建议。

## 安装与调用

下载这个仓库，将包含 `SKILL.md` 的整个文件夹放入你的 AI 工具支持的技能目录。

Codex 用户可将文件夹命名为 `boji-life`，放入自己的 `.codex/skills/` 目录。重新加载技能列表后，在新聊天中调用：

```text
请用 $boji-life 分析我的生活选择：
我想换工作，但担心不稳定。
我的时间、预算和目前情况是……
```

也可以问：

```text
用 $boji-life 看看，为什么我买了很多课程还是学不会？
```

```text
请用 $boji-life 帮我找一个适合当前时间、预算和身体情况的训练起点。
```

```text
用 $boji-life 帮我判断，我是真的想做这个选择，还是被别人的期待推着走？
```

自动选择已开启，适合的生活决策问题可以被模型识别使用。实际触发取决于工具和模型；显式输入 `$boji-life` 更清楚。
